# 경기지역화폐 예약 클릭 (Android)

매월 1일 **한국 시간 오전 9시**에, 사용자가 선택한 경기지역화폐 앱에서 **빠른 충전 바로가기 → 수원시** 버튼을 한 번씩 누르는 개인용 보조 앱입니다. 지역 선택 후 종료하며 금액 입력, 충전 확정, 인증, 결제는 하지 않습니다.

## 설치와 설정

1. Android 8.0 이상 기기에 APK를 설치합니다.
2. 앱에서 설치된 **경기지역화폐**를 대상으로 선택합니다. 패키지명을 추측하지 않고 직접 선택하게 되어 있습니다.
3. Android 접근성 설정에서 **지역화폐 예약 클릭** 서비스를 켭니다. 외부 설치 앱은 기기 설정의 앱 정보 메뉴에서 **제한된 설정 허용**이 먼저 필요할 수 있습니다.
4. Android 12 이상에서는 **정확한 알람** 권한을 허용합니다.
5. **10초 후 시험 실행**으로 실제 기기에서 먼저 확인합니다. 확인 후 10초 안에 대상 앱의 빠른 충전 화면을 열어 두세요. 시험 실행도 실제 두 버튼을 누릅니다.
6. **매월 예약 켜기**를 누릅니다. 실행일에는 9시 전에 화면 잠금을 풀고 빠른 충전 화면을 열어 두세요. 시스템 자동 날짜·시간을 사용하세요.

**예약 끄기 · 실행 중지**는 월간 예약과 시험 예약을 취소하고 진행 중인 클릭도 중단합니다. 앱 화면에서 다음 예약과 마지막 결과를 확인할 수 있습니다.

## 실행 준비와 클릭 기록

- 화면 유지 오버레이와 시스템 바를 대상 앱으로 오인하지 않도록 표시 중인 앱 창들을 확인합니다. 다른 앱이 위에 있거나 시스템 창이 가리면 클릭하지 않고, 목표 시각 이후 최대 15초 동안 대상 화면을 다시 확인합니다. 순간적으로 창을 읽지 못했다고 즉시 실패하지 않습니다. `화면 진단`에서 선택한 앱과 감지된 창의 차이를 확인할 수 있습니다. 창 진단은 패키지명과 상태만 기록하며 화면 본문은 저장하지 않습니다.

- 실행 2분 전부터 접근성 서비스가 대상 화면과 버튼을 미리 확인합니다. 매월 1일 **08:58 이후** 잠금을 풀고 대상 화면을 열어 두면 `준비 완료` 상태를 확인할 수 있습니다. 시험 실행은 예약 직후부터 준비합니다.
- 준비 중 버튼을 보관하고 화면 변경 이벤트 및 실행 1초 전에 다시 확인합니다. 클릭 직전에는 현재 대상 앱·화면과 버튼의 유일성을 재검증합니다. 같은 문구의 서로 다른 버튼이 여러 개면 클릭하지 않습니다. 지역 선택은 `충전하실 지역` 안내가 보일 때만 실행합니다.
- 대상 앱이 전면에 있는 준비·실행 구간에만 터치를 가로채지 않는 1×1 접근성 오버레이와 제한 시간 WakeLock으로 화면 자동 꺼짐을 방지합니다. 완료·실패·중지 시 해제하며 다른 앱으로 전환하면 화면 유지를 해제합니다. 전원 버튼으로 끄거나 잠근 화면을 자동으로 해제하지 않습니다.
- `준비`, `대기`, `준비 완료`, `클릭 중`, `클릭 요청 완료`, `실패`, `중지` 상태와 화면 유지 여부를 표시합니다. 접근성 제한이 있으면 앱의 **앱 정보 열기 → ⋮ → 제한된 설정 허용** 안내를 따라 설정하세요.
- 목표 시각, 첫 클릭 호출 시각, 마지막 클릭 버튼·시각과 목표 대비 지연(ms)을 표시합니다. 기기 시각 기준이며 서버 도착이나 충전 완료를 나타내지 않습니다. 준비 구간의 대기는 단조 시계를 사용하고, 기기 시간 변경 통지가 오면 준비를 다시 설정합니다.
- 알람과 서비스 타이머가 함께 도착해도 예약을 한 번만 소비합니다. 클릭이 접수된 단계는 반복하지 않으며 클릭 요청이 거부되면 중지합니다.
- 서버 시각 동기화는 구현하지 않았습니다. 참고 앱의 병원 서버 주소를 재사용하지 않으며 경기지역화폐의 검증된 서버 시간 근거가 필요합니다.

## 동작과 제한

- `AlarmManager.setExactAndAllowWhileIdle`로 매월 다음 실행을 예약합니다. 기기 재부팅, 앱 업데이트, 시간 변경 시 월간 예약을 복원합니다. 강제 종료 후에는 앱을 열고 예약을 다시 켜세요. 정확한 알람 권한을 취소했다가 다시 허용하면 앱에서 예약 상태를 확인하세요.
- 화면이 꺼졌거나 잠겼거나 다른 앱이 전면에 있으면 클릭을 중단합니다. 잠금 해제나 백그라운드 앱 실행은 자동화하지 않습니다. 제조사 절전 설정에 따라 서비스가 종료될 수 있습니다.
- 알람 수신이 15초를 초과해 늦으면 해당 실행을 건너뜁니다. 목표 시각부터 최대 15초 동안 버튼을 찾고, 같은 단계를 반복 클릭하지 않습니다. **운영체제 지연·기기 시계 오차·서버 대기 때문에 09:00:00 실행이나 충전 성공을 보장하지 않습니다.**
- 접근성 트리의 버튼 글자와 클릭 가능한 상위 요소를 이용합니다. 대상 앱이 글자를 노출하지 않거나 화면 구성이 바뀌면 실패할 수 있습니다. 이미지 좌표 클릭이나 인증 우회는 하지 않습니다.
- 지역 선택 창을 미리 열었다면 지역 선택 단계부터 실행합니다. 성공 기록은 Android가 클릭 요청을 받아들였다는 의미이며, 충전이나 화면 전환 완료 확인은 아닙니다.
- 인터넷 권한이 없으며 화면 내용·인증 정보·계좌 정보를 수집하거나 전송하지 않습니다. 설정·실행 상태·첫/마지막 클릭 시각과 마지막 결과만 기기에 저장합니다. 접근성 탐지는 짧은 준비·실행 구간에만 사용합니다.
- 수원시 오전 9시 기준입니다. 첨부 화면의 용인시·화성시는 시간이 다르므로 대상에 포함하지 않았습니다. 비공식 개인용 앱이며 실제 이용 전 서비스 이용 조건을 확인하세요.

## 빌드

### GitHub 자동 서명 빌드와 릴리스

[MyExercise](https://github.com/layland/MyExercise)와 같은 분리 빌드 방식을 사용합니다.

1. 소스는 **layland/GyeonggiCash main**에 저장합니다.
2. **layland/MyParkingAndroid의 build/gyeonggicash 전용 브랜치**에서 GyeonggiCash main을 내려받고 기존 Android Secrets로 서명 빌드합니다. 주차앱의 기본 브랜치와 MyExercise 빌드 브랜치는 변경하지 않습니다.
3. 빌드 원본은 `gyeonggicash-v0.1.N` 태그로 구분하고 주차앱의 최신 릴리스 표시를 변경하지 않습니다.
4. 이 프로젝트의 게시 workflow가 원본 APK의 SHA-256, 서명, 패키지명과 내부 버전을 검증한 뒤 **[GyeonggiCash Releases](https://github.com/layland/GyeonggiCash/releases)**에 그대로 게시합니다. 재서명하거나 키를 공개하지 않습니다.

빌드 브랜치 push 시 서명 빌드가 시작됩니다. 에이전트 수정 작업에서는 소스 push 후 빌드 브랜치도 push하여 새 빌드를 실행합니다. 게시 workflow는 이 저장소 main push, 수동 실행, 15분 주기 예약 실행을 지원합니다. GitHub 예약 실행은 지연될 수 있습니다.
main push로 시작된 게시 작업은 해당 소스 커밋으로 만든 서명 APK를 최대 10분 기다리므로 이전 APK를 새 변경의 결과로 잘못 게시하지 않습니다. 서명 빌드 브랜치가 실행되지 않았거나 실패하면 기다린 후 오류를 표시합니다.

서명키는 기존 빌드 저장소 Secrets에서만 사용하므로 GyeonggiCash에 새 Secrets를 등록할 필요가 없습니다. 이 앱은 동일한 키로 계속 서명해야 업데이트할 수 있습니다. 앱 전용 키로 전환하고 싶다면 기존 키 등록 스크립트는 별도로 사용할 수 있습니다.

### 로컬 빌드

Android Studio에서 프로젝트를 열고 SDK 35, JDK 17, Gradle 8.9로 빌드하세요. Gradle 실행 파일은 저장소에 포함하지 않았습니다.

```sh
gradle :app:assembleDebug :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

순수 Java 예약 계산 검증(JDK 17 이상):

```sh
bash tools/test.sh
```

월 경계, 연말, 윤년, 한국 시간과 지연 허용 범위를 검증합니다. 실제 경기지역화폐 화면·접근성 노출·절전 상태·재부팅 후 동작은 Android 실기기에서 확인해야 합니다. GitHub Actions에서 릴리스 APK 빌드, Android Lint, APK 서명·패키지명·버전 검증을 통과했습니다. Android 실기기 동작은 아직 검증하지 않았습니다.
