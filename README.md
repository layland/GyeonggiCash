# 경기지역화폐 예약 클릭 (Android)

매월 1일 **한국 시간 오전 9시**에, 사용자가 선택한 경기지역화폐 앱에서 **빠른 충전 바로가기 → 수원시** 버튼을 한 번씩 누르는 개인용 보조 앱입니다. 지역 선택 후 종료하며 금액 입력, 충전 확정, 인증, 결제는 하지 않습니다.

## 설치와 설정

1. Android 8.0 이상 기기에 APK를 설치합니다.
2. 앱에서 설치된 **경기지역화폐**를 대상으로 선택합니다. 패키지명을 추측하지 않고 직접 선택하게 되어 있습니다.
3. Android 접근성 설정에서 **지역화폐 예약 클릭** 서비스를 켭니다. 외부 설치 앱은 기기 설정의 앱 정보 메뉴에서 **제한된 설정 허용**이 먼저 필요할 수 있습니다.
4. Android 12 이상에서는 **정확한 알람** 권한을 허용합니다.
5. **10초 후 시험 실행**으로 실제 기기에서 먼저 확인합니다. 확인 후 10초 안에 대상 앱의 빠른 충전 화면을 열어 두세요. 시험 실행도 실제 두 버튼을 누릅니다.
6. **매월 예약 켜기**를 누릅니다. 실행일에는 9시 전에 화면 잠금을 풀고 빠른 충전 화면을 열어 두세요. 시스템 자동 날짜·시간을 사용하세요.

**예약 끄기 · 실행 중지**는 월간 예약과 시험 예약을 취소하고 진행 중인 클릭도 중단합니다. 앱 화면에서 다음 예약과 마지막 결과를 확인할 수 있습니다.

## 동작과 제한

- `AlarmManager.setExactAndAllowWhileIdle`로 매월 다음 실행을 예약합니다. 기기 재부팅, 앱 업데이트, 시간 변경 시 월간 예약을 복원합니다. 강제 종료 후에는 앱을 열고 예약을 다시 켜세요. 정확한 알람 권한을 취소했다가 다시 허용하면 앱에서 예약 상태를 확인하세요.
- 화면이 꺼졌거나 잠겼거나 다른 앱이 전면에 있으면 클릭을 중단합니다. 잠금 해제나 백그라운드 앱 실행은 자동화하지 않습니다. 제조사 절전 설정에 따라 서비스가 종료될 수 있습니다.
- 알람 수신이 15초 이상 늦으면 해당 실행을 건너뜁니다. 실행 시작 후 최대 15초 동안 버튼을 찾고, 같은 단계를 반복 클릭하지 않습니다. **운영체제 지연·기기 시계 오차·서버 대기 때문에 09:00:00 실행이나 충전 성공을 보장하지 않습니다.**
- 접근성 트리의 버튼 글자와 클릭 가능한 상위 요소를 이용합니다. 대상 앱이 글자를 노출하지 않거나 화면 구성이 바뀌면 실패할 수 있습니다. 이미지 좌표 클릭이나 인증 우회는 하지 않습니다.
- 지역 선택 창을 미리 열었다면 지역 선택 단계부터 실행합니다. 성공 기록은 Android가 클릭 요청을 받아들였다는 의미이며, 충전이나 화면 전환 완료 확인은 아닙니다.
- 인터넷 권한이 없으며 화면 내용·인증 정보·계좌 정보를 수집하거나 전송하지 않습니다. 설정과 마지막 실행 결과만 기기에 저장합니다. 접근성 기능은 선택한 앱이 전면에 있는 짧은 실행 구간에만 사용합니다.
- 수원시 오전 9시 기준입니다. 첨부 화면의 용인시·화성시는 시간이 다르므로 대상에 포함하지 않았습니다. 비공식 개인용 앱이며 실제 이용 전 서비스 이용 조건을 확인하세요.

## 빌드

Android Studio에서 프로젝트를 열고 SDK 35, JDK 17, Gradle 8.9로 빌드하세요. Gradle 실행 파일은 저장소에 포함하지 않았습니다.

```sh
gradle :app:assembleDebug :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

순수 Java 예약 계산 검증(JDK 17 이상):

```sh
bash tools/test.sh
```

월 경계, 연말, 윤년, 한국 시간과 지연 허용 범위를 검증합니다. 실제 경기지역화폐 화면·접근성 노출·절전 상태·재부팅 후 동작은 Android 실기기에서 확인해야 합니다. 현재 이 환경에는 Android SDK가 없어 Android 빌드와 실기기 검증은 수행하지 않았습니다.
